# 01 - Product

## What it is
A web app for building a portfolio landing page by choosing a design, choosing colors, and filling in data. The result is a real, fast, responsive web page that can be published on a link or downloaded as HTML.

## Who it is for

| User | What they want | Sections they need most |
|---|---|---|
| Job seeker / student | Get hired | About, experience, education, skills, languages, projects, CV download |
| Freelancer / creative | Get clients | Services, project gallery, testimonials, pricing, contact form |
| Company / agency | Look trustworthy | Services, team, clients' logos, case studies, numbers, map |
| Startup | Get users or investors | Problem/solution, features, traction numbers, team, press, waitlist |
| Anything else | A good-looking page fast | Free choice from the full library |

## Why it is stronger than Canva for portfolios

| | Canva | Portfolio Maker |
|---|---|---|
| How a page is built | Drag boxes on a canvas by hand | Fill in data, sections arrange themselves |
| Changing design | Rebuild or fix by hand | One click, content stays |
| Mobile | Often needs manual fixing | Every section responsive by default |
| Portfolio-specific data | None, just text boxes | Real fields: experience, education, skills with levels, languages |
| Guidance | Blank page or generic template | Questions first, then ideas made for that user |
| Arabic / right-to-left | Weak | Built in, including two-language pages |
| Output | Canva-hosted site | Clean HTML download + hosted link + PDF CV |
| Speed and SEO | Heavy pages | Light static HTML, SEO fields, share image |

We do not try to beat Canva at free-form graphic design. We beat it at one job: the best portfolio page in the shortest time.

## Features

### Version 1 (must have)
- Sign up and log in (email + Google).
- Onboarding questions and 6 generated starter ideas.
- Section library: about 35 section types, most with 2 to 4 layout variants.
- 12 design families, ready palettes plus custom color with automatic contrast checking, font pairs.
- Editor: add, remove, reorder, hide, duplicate sections; edit content in forms; switch variant; change theme.
- Live preview on desktop, tablet, phone sizes.
- Image upload with crop.
- Autosave, undo and redo.
- Publish to `ourdomain.com/p/name`. Download as HTML zip.
- English and Arabic content with correct direction.
- Dashboard: list, duplicate, rename, delete portfolios.

### Version 2 (makes it powerful)
- Click text in the preview to edit it in place.
- Import from a CV file (PDF) or LinkedIn export to fill the data automatically.
- AI writing help for about text, project descriptions, taglines.
- Download a matching PDF CV from the same data.
- Working contact form with inbox in the dashboard.
- Visitor statistics.
- Custom domain.
- Scroll animations and dark/light switch per portfolio.
- Version history.
- Extra pages (for example, a page per project).

### Not building
- Free-form canvas with drag-anywhere elements.
- Online shop or payments inside user portfolios.
- A blog system.

## Success measures
- A new user reaches a published page in under 10 minutes.
- At least 60% of users who finish onboarding publish.
- Published pages score 90+ on Lighthouse for performance and accessibility.
